# Prática 2.3 — Diagramas que explicam de verdade

## Entrega

Um mapa de fluxo editável acompanhado de uma explicaçêo simples.

## Exercício

Crie um fluxo para o pedido descrito no tópico. Identifique a decisêo, o retorno e a saída. Explique como o desenho se comporta quando o contato está ausente.

## Critérios

- [ ] O desenho corresponde ao enunciado.
- [ ] Pedido incompleto tem caminho explícito.
- [ ] Existe uma representaçêo editável.
